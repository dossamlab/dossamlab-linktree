# 쇼룸형 링크트리 설계

- 날짜: 2026-10-03
- 브랜치: `showroom` (main과 dossamlink.vercel.app 운영 화면은 그대로 둔다)
- 상태: 설계 확정, 구현 전

## 목표

지금의 링크트리(알약 목록 + 패널)를, 3D 미니어처 그림 카드가 흐르고 스크롤에 반응하는 쇼룸형 페이지로 새로 만든다. PC와 폰에서 같은 장면을 보여 준다. DoRms 전용이 아니라 도쌤 개인 링크트리로 쓴다.

참고한 곳: AI EDU Showroom 공개 첫 화면. 구성(큰 제목, 정보 칩, 기울어진 카드가 흐르는 띠)만 참고하고 그 사이트의 그림과 문구는 가져오지 않는다.

## 확정한 결정

| 항목 | 결정 |
|---|---|

| 카드 그림 | 3D 미니어처 화풍 AI 일러스트. 아스트라(Codex의 GPT-6 Astra)가 생성 |
| 페이지 구성 | 첫 화면 + 흐르는 띠 + 묶음별 진열장 |

| 라이브러리 | `motion` 하나 (MIT, 무료, React 19 지원). GSAP는 쓰지 않는다 |
| 테마 | B. 밤의 과학관 (별이 깔린 남색 전시장, 금빛 나선) |
| 최상단 문구 | `청학고 교사 도쌤` |
| 큰 제목 | `Dossam Lab` |

## 화면 구성

1. **첫 화면**
   - 문구: 위 칩 `청학고 교사 도쌤`, 큰 제목 `Dossam Lab`, 소개 한 줄(`웹앱으로 신나는 학교를 만들어보고 싶은 도쌤의 링크트리`).
   - 묶음 칩: `도름스 활동 6`, `과학 웹앱 8`, `학급 도구 3`. 숫자는 설정 파일에서 센다.
   - 버튼 3개: `전체 보기`(진열장으로 스크롤), 그리고 설정 파일의 바로가기 링크 이름 그대로 `인스타그램`, `연락처`(메일).
   - 배경: 남색 바탕, 별 점, 위쪽 은은한 빛. 배경 그림이 있으면 그 위에 흐리게 깐다.
2. **흐르는 띠**
   - 모든 링크 카드(인스타그램과 메일 제외)가 살짝씩 기운 채 오른쪽에서 왼쪽으로 끝없이 흐른다.
3. **묶음별 진열장**
   - 01 도름스 커뮤니티 나의 활동, 02 수업에서 바로 쓰는 과학 웹앱, 03 학급 운영과 업무 도우미 순서. 01이 항상 맨 위다.
   - 칸 수: 넓은 화면 4열, 태블릿 3열, 폰 2열.
4. **아래쪽**
   - 인스타그램과 연락처를 이름과 설명(예: `연락처 / dossamlab@gmail.com`)이 든 알약 버튼으로 둔다. 이 둘은 상세 없이 바로 이동한다.

## 연출 5가지

1. **등장 순서**: 처음 열 때 한 번만 재생한다.
   - 칩(0초) → 제목 글자 단위(0.18초부터 글자마다 0.045초 간격, 아래에서 솟으며 살짝 회전이 풀림) → 소개(0.8초) → 묶음 칩(0.95초부터 0.08초 간격) → 버튼(1.1초) → 띠(1.2초에 오른쪽에서 밀려 들어옴).
2. **띠 스크롤 관성**
   - 기본 속도는 초당 약 40px.
   - 스크롤하면 스크롤 속도에 비례해 같은 방향으로 빨라진다. 위로 스크롤하면 잠깐 거꾸로 흐른다.
   - 스프링처럼 원래 속도로 돌아온다.
   - 마우스를 올리거나, 터치하거나, 키보드 초점이 들어오면 멈춘다.
3. **카드 기울기 탄성**: 마우스가 있는 기기에서만 동작한다.
   - 커서 위치를 따라 최대 X축 8도, Y축 10도 기운다. 스프링이라 살짝 출렁인다.
   - 커서 쪽에 빛 반사가 생긴다.
4. **나선 선 그리기**
   - 진열장 왼쪽 여백을 따라 내려가는 금빛 나선 선이 진열장 스크롤 진행만큼 그려진다.
   - 선이 각 묶음 제목 높이에 닿으면 그 자리 점이 톡 튀어나온다.
   - 폰에서는 선을 더 가늘게 하고 카드 뒤에 둔다.
5. **카드 펼침 상세**
   - 카드를 누르면 그 카드가 그 자리에서 커져 상세 패널이 된다(공유 레이아웃 전환).
   - 패널 내용: 큰 그림, 분류, 이름, 설명, 묶음 이름, 큰 `바로가기` 버튼, 닫기 버튼.
   - 닫는 방법: 닫기 버튼, Esc, 바깥 클릭. 닫으면 원래 카드로 줄어들고 키보드 초점도 그 카드로 돌아간다.
   - 레이아웃: PC는 그림 왼쪽과 글 오른쪽(최대 폭 880px), 폰은 그림 위와 글 아래.
   - 외부 링크는 새 탭으로 연다.

추가 카드 효과: 진열장 카드는 화면에 들어올 때 아래에서 살짝 뒤로 젖혀진 채 떠올라 제자리에 선다. 묶음 안에서는 0.06초 간격으로 순서대로 선다.

넣지 않는 것: 스크롤 중 화면 고정, 브라우저 스크롤 가로채기, 커서를 따라다니는 원, 글자 뒤섞기.

## 데이터 변경 (`src/config/linktree.ts`)

- `profile`을 새 화면에 맞게 정리한다.
  - `title: "청학고 교사 도쌤"`: 위 칩과 브라우저 탭 제목.
  - `heroTitle: "Dossam Lab"`.
  - `description`: 소개 한 줄.
  - 옛 화면에서만 쓰던 필드는 지운다.
- 링크 항목(`LinkItem`)에 세 필드를 더한다.
  - `id: string`(필수): 영문 소문자와 하이픈으로 된 고유 이름, 예: `gamma-grand-prix`. 그림 파일 이름과 같다.
  - `tag: string`(필수): 짧은 분류, 예: `물리 레이싱`.
  - `cover?: string`: 그림 경로의 앞부분, 예: `/visuals/covers/gamma-grand-prix`. 코드가 `-480.webp`, `-960.webp`를 붙여 크기별로 고른다.
- 묶음(`group`)에 `shortName`을 더한다. 첫 화면 칩에 쓴다(`도름스 활동`, `과학 웹앱`, `학급 도구`).
- `cover`가 없으면 카드에 테마 색 블록과 기존 아이콘(`thumb`)을 보여 준다. 그림이 생기면 경로만 채운다.
- 프로필 카드는 `cover` 대신 `/assets/dorms-community.png`를 쓴다(저장소 고정 규칙).
- 고정 규칙 유지: 첫 묶음은 `도름스 커뮤니티 나의 활동`, 다른 제작자 앱(세포 이스케이프, 딱! 이만큼)은 넣지 않는다.
- `src/config/theme.ts`는 위 테마 B 토큰으로 바꾼다. 지금처럼 루트 요소의 CSS 변수로 넘긴다.

## 코드 구조

`src/components/showroom/` 아래 파일 하나에 부품 하나:

| 파일 | 하는 일 |
|---|---|
| `utils.ts` | 묶음·링크 목록 정리, 공용 타입(`ShowItem`, `OpenCard`), 새 탭 속성, 공용 곡선 값 |
| `CardArt.tsx` | 카드 그림 또는 대체 블록. 카드와 상세가 같이 쓴다 |
| `Showroom.tsx` | 페이지 뼈대, CSS 변수, `MotionConfig`(움직임 줄이기 존중), 옛 주소 `?tab=` 처리, 상세 열림 상태 |
| `Hero.tsx` | 첫 화면과 등장 순서 |
| `Marquee.tsx` | 흐르는 띠와 스크롤 관성, 멈춤 |
| `ShowcaseCard.tsx` | 카드 한 장(그림 또는 대체 블록, 분류, 이름), 기울기 탄성, 공유 레이아웃 id. 띠와 진열장이 같이 쓴다 |
| `Catalog.tsx` | 묶음별 진열장과 카드 떠오름 |
| `SpiralPath.tsx` | 나선 선과 묶음 점 |
| `CardDetail.tsx` | 펼침 상세 패널 |

- `src/app/page.tsx`는 `?tab`을 받아 `Showroom`에 넘긴다.
- `src/app/layout.tsx`는 글꼴과 메타데이터를 맡는다.
- `src/app/globals.css`는 새 화면용으로 다시 쓴다.
- 옛 `src/components/LinkTree.tsx`와 `@paper-design/shaders-react` 패키지는 지운다.
- 같은 링크가 띠와 진열장에 동시에 보이므로, 공유 레이아웃 id는 `marquee-항목id`와 `catalog-항목id`로 나눈다. 상세 패널은 누른 카드의 id를 이어받는다.
- 띠의 복제 카드(끊김 없는 반복용)는 같은 링크를 다시 보여 주기만 한다. `aria-hidden`과 `tabIndex=-1`로 화면 읽기와 탭 이동에서 빼고, 마우스로 눌렀을 때도 펼쳐지도록 따로 `marquee-clone-항목id`를 붙인다.
- 상세가 열려 있는 동안 띠는 멈춘다(펼쳐지는 카드가 움직이지 않도록).

## 그림

- 화풍: 3D 미니어처 디오라마(점토와 장난감 질감, 틸트시프트 사진 느낌). 남색 바탕에 조명을 받은 전시품처럼 그린다. 글자는 넣지 않는다.
- 수량: 링크 16장(4:5 세로) + 첫 화면 배경 1장(16:9 가로).
- 작업 분담:
  - 아스트라는 `docs/showroom-art-brief.md`를 보고 원본 PNG를 `art-raw/`(git 제외 폴더)에 저장만 한다. git은 다루지 않는다.
  - Claude가 WebP 두 크기로 바꿔 넣고 커밋한다.
    - 카드: `public/visuals/covers/항목id-480.webp`, `-960.webp`.
    - 배경: `public/visuals/hero-bg-1280.webp`, `-2400.webp`. 파일이 없으면 별 배경만 보인다.
- 그림이 오기 전에도 페이지는 대체 블록으로 완전히 동작해야 한다.

## 접근성과 예외

- 기기에서 움직임 줄이기를 켜 둔 사람: 연출 5가지의 위치·회전·크기 움직임을 모두 끈다(은은한 투명도 변화만 남는다). 띠는 멈춘 채 가로로 넘겨 볼 수 있다. 기울기는 동작하지 않는다. 나선은 다 그려진 상태로 보여 준다.
- 모든 카드는 키보드로 닿고 Enter로 상세를 연다. 상세가 열리면 첫 초점은 `바로가기` 버튼에 둔다.
- 그림 파일이 없거나 불러오지 못하면 대체 블록을 보여 준다.
- 화면 문구는 쉬운 한국어로 쓰고 긴 줄표 문자는 쓰지 않는다(저장소 규칙).

## 추가 결정: 3D 조형물과 묶음 표장 (2026-10-03)

사용자가 Blender, 아스트라, Meshy AI 활용을 제안해 A(첫 화면 조형물)와 B(묶음 표장)를 넣기로 했다. 브라우저 실시간 3D(three.js)는 무게와 화질 문제로 넣지 않는다.

- 만드는 길: 아스트라(콘셉트 그림) → Meshy(소품 3D 모델, `art-raw/3d/*.glb`) → Blender(`scripts/blender/sculpture.py`가 받침대·행성·금빛 나선 궤도·조명을 만들고 소품을 궤도에 올려 렌더) → `npm run art`(WebP 변환).
- 첫 화면 조형물: 60장 회전 렌더(배경 투명)를 캔버스에 그린다. 가만히 있으면 10초에 한 바퀴, 화면을 지나가는 스크롤 동안 한 바퀴를 더 돈다. 조형물 받침대 아래쪽은 흐르는 띠가 덮어 깊이감을 준다. 용량은 PC 720px 약 2.8MB, 폰 480px 약 1.9MB이며 첫 장을 먼저 보여 준다. 1080px로 렌더한 뒤 60장 전체가 차지하는 범위로 똑같이 잘라 여백을 없앤다. 움직임 줄이기 설정이면 첫 장에 멈춘다.
- 묶음 표장: 01 금빛 나선 토큰, 02 플라스크와 금빛 궤도, 03 새싹. 묶음 제목 옆 64px(폰 48px), 천천히 떠오르는 움직임.
- Meshy 소품이 없으면 Blender 기본 도형으로 대신하므로 페이지는 언제나 완성된 상태다. 소품이 도착하면 같은 명령으로 다시 렌더한다.
- Meshy는 사용자 계정 크레딧을 쓴다. 무료 요금제 결과물의 사용 조건은 사용자가 확인한다.
